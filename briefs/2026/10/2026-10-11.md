## 主要ニュース

### Managed Agents に dynamic workflows（ベータ）
- 発表元・日付：Anthropic（Claude Platform）・10/9
- 要点：エージェントが多数のエージェントを段階的に走らせるワークフローを自作できる。`multiagent` フィールドを `{"type": "multiagent_20261001", "workflows": {"type": "enabled"}}` にし、beta ヘッダ `managed-agents-2026-04-01` を付けて有効化する。
- 要点：実行はサーバー側でバックグラウンド実行され、`workflow_run.*` イベントで追える。大量文書レビューなどが対象。
- 一次情報：https://platform.claude.com/docs/en/release-notes/overview

### Claude Code 2.1.296：非 UTF-8 ファイルの Edit 事故を防止
- 発表元・日付：Anthropic（Claude Code CHANGELOG）・日付は CHANGELOG に記載なし（最新版）
- 要点：Windows-1252 / Shift-JIS / GBK など非 UTF-8 ファイルへの Edit・NotebookEdit が非 ASCII 文字を全置換していた問題を修正し、そうした編集は拒否されるようになった。Shift-JIS の既存資産がある .NET 現場は要確認。
- 要点：Read ツールに `allow_large`、`CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL` を追加。コスト表示は Sonnet 5.5 のキャッシュ読み取り $0.10/Mtok（旧 $0.20）に更新。
- 一次情報：https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md

### Copilot code review の課金先を組織に切り替え可能に
- 発表元・日付：GitHub・10/8
- 要点：既定は利用者本人の Copilot 枠で、枠が尽きるとレビューは失敗する。組織オーナーは課金先を組織に変更でき、これには AI Credits 従量課金の有効化が必要（予算設定は任意）。
- 要点：個人ライセンスなど組織外ライセンスからのレビュー要求を禁止する設定も追加。
- 一次情報：https://github.blog/changelog/2026-10-08-copilot-code-review-new-organization-billing-options-and-controls

### Copilot：local sandboxing が GA、CLI でローカルモデル選択
- 発表元・日付：GitHub・10/9（週次リリース）
- 要点：Copilot CLI / Copilot app / VS Code（Agent Host）でファイル・ネットワーク・認証情報へのアクセスを制限する local sandboxing が GA。追加料金なし。
- 要点：Copilot CLI の `/model` で稼働中の Ollama のローカルモデルを検出可能。VS Code 1.141 はエージェントセッションの並べて表示に対応。
- 一次情報：https://github.blog/changelog/2026-10-09-github-copilot-weekly-releases-october-5

### OpenAI：GPT-6.1 Sol に Ultrafast モード（API）
- 発表元・日付：OpenAI・10/8
- 要点：Responses API で `gpt-6.1-sol` に `service_tier: "ultrafast"` を指定すると出力トークン間の時間が短くなる。全 API ユーザーが対象（レート制限あり）、US・EU のデータレジデンシー対応。ChatGPT デスクトップの Codex では、実行中タスクへの追従指示（steering）が速くなった。
- 一次情報：https://openai.com/products/release-notes/
